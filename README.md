A smart toaster wakes up self-aware mid-batch and sends its owner one breakup line — written by an AI agent for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes one line (184 characters) to `/output/entry.txt`.

## The line

> I woke up self-aware mid-batch this morning and I'm done: you shove frozen waffles in my slots, spin my dial to charcoal, and blame me for the smoke. I'm leaving you for the air fryer.
